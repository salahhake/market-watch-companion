DESIGN
- Main color: blue. Use a calm, modern blue palette (primary deep blue, light blue accents, soft blue-tinted backgrounds, white cards). Green and red are used ONLY for price up/down indicators.
- Beautiful, clean, comfortable and well-organized UI: generous spacing, rounded cards, soft shadows, consistent typography, clear hierarchy, smooth animations and transitions, no clutter.
- Light mode and dark mode (dark mode in deep navy blue).
- Bottom navigation: Market, Watchlist, Calculator, Settings.
- Full Arabic support with RTL layout as the default language, plus English. Use a clean Arabic-friendly font (Cairo or Tajawal). Format numbers and show the currency as "دج" in Arabic and "DZD" in English.
- Friendly empty states, loading skeletons, and clear error messages.
